# 🎙️ Tool Giọng Nói - F5-TTS Vietnamese & Multi-TTS Platform

Công cụ chuyển đổi văn bản thành giọng nói (TTS) và nhân bản giọng nói tiếng Việt cao cấp hỗ trợ đa nền tảng:
- 🚀 **F5-TTS Vietnamese ViVoice 1000h (Colab GPU)**: Nhân bản giọng nói chỉ từ 3-10 giây audio mẫu.
- ⚡ **Multi-Key Rotation**: Tự động xoay vòng danh sách API Key không giới hạn khi hết quota.
- 🎧 **Offline Mode & Online Services**: Hỗ trợ đầy đủ các dịch vụ TTS tiếng Việt hàng đầu.

## 🚀 Cách chạy trên Google Colab (F5-TTS 1000h GPU)

1. Mở [Google Colab](https://colab.research.google.com/), chọn Runtime: **T4 GPU**.
2. Dán đoạn mã script từ tab **"Colab GPU"** trên giao diện web.
3. Chạy script để nhận link Cloudflare/Gradio URL.
4. Dán link vào ô **"Link Colab API"** và bấm **"Bắt Đầu Clone Giọng"**.

## 💻 Cách chạy Web Local

```bash
# Cài đặt thư viện
npm install

# Khởi chạy chế độ phát triển
npm run dev
```
Truy cập: `http://localhost:3000`
